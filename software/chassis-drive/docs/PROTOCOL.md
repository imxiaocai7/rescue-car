# 独立项目的通信验收协议 v1

此文描述原诊断协议。新运动协议及运动固件对 v1 的兼容行为见 [MOTION_PROTOCOL.md](MOTION_PROTOCOL.md)，尚未实物验收。

仅提供 PING（1）和 STOP（2），没有速度字段、运动授权或解除锁定指令。
STOP 在本版只确认诊断请求，不证明电机端口电平或物理停车。本版不包含电机控制实现。

所有整数为小端无符号整数。CRC 使用 CRC-32/ISO-HDLC，与 Python zlib.crc32 一致。

| 请求偏移 | 长度 | 内容 |
|---|---|---|
| 0 | 4 | ASCII CDP1 |
| 4 | 4 | 请求序号 |
| 8 | 1 | 1=PING，2=STOP |
| 9 | 3 | 保留，必须为零 |
| 12 | 4 | 前12字节CRC32 |

| 回复偏移 | 长度 | 内容 |
|---|---|---|
| 0 | 4 | ASCII CDS1 |
| 4 | 4 | 被确认的请求序号 |
| 8 | 4 | STM32启动毫秒计数 |
| 12 | 4 | 固件标识0x20261007 |
| 16 | 4 | 标志1：未实现电机控制 |
| 20 | 4 | 前20字节CRC32 |

序号只关联请求和回复，不是运动防重放或身份认证。固件标识也不是安全认证。
电脑每次只有一个待确认请求，超过期限、序号不符或MCU计时回退时结束测试，不自动重连。
TCP/UART都是字节流，必须处理分片、粘包、乱码及CRC错误。解析器使用固定长度滑动窗口。
收到未知操作或错误CRC不回应。未来运动协议需要另行设计授权、租约与安全输出，不能直接解除本版限制。
